## Repository

The repository contains four primary layers:

1. **Design** — the generated Meshery design artifact.
2. **Specification** — architecture, components, relationships and decisions.
3. **Generation** — deterministic generation of the design artifact.
4. **Validation** — structural and runtime verification.
